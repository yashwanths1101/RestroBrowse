# RestroBrowse

A **restaurant discovery platform** built with React that lets users browse restaurants, search by name, filter by rating, and explore restaurant menus.

## Screenshots

## Features

- **Restaurant Listing:** Browse restaurants using locally stored data.
- **Search:** Find restaurants by name.
- **Rating Filter:** Filter restaurants based on ratings.
- **Restaurant Details:** Explore individual restaurant pages and menus.
- **Menu Categories:** Navigate menu items by category.
- **Lazy Loading:** Load components when needed.
- **Shimmer UI:** Display loading placeholders while data is being fetched.
- **Client-Side Routing:** Navigate between pages using React Router.

## Tech Stack

- **Frontend:** React, JavaScript (ES6+), HTML5, CSS3
- **Styling:** Tailwind CSS
- **Routing:** React Router
- **Build Tool:** Vite

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/)
- npm

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/yashwanths1101/RestroBrowse.git
   ```

2. Navigate to the project directory:

   ```bash
   cd RestroBrowse
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

### Run Locally

```bash
npm run dev
```

### Production Build

```bash
npm run build
```
